# 3D QUEST — Секрет втраченого виміру

Навчальна браузерна гра-квест для учнів 9 класу НУШ за § 4.1 «Тривимірна графіка. Принципи тривимірного моделювання».

## Запуск локально
1. Завантажте або розпакуйте всі файли проєкту.
2. Відкрийте `index.html` у сучасному браузері.
3. Для завантаження Three.js потрібне підключення до інтернету.

## Публікація на GitHub Pages
1. Створіть на GitHub новий публічний репозиторій, наприклад `3d-quest-9`.
2. Завантажте в корінь репозиторію файли `index.html`, `style.css`, `game.js`, `README.md`.
3. Відкрийте **Settings → Pages**.
4. У блоці **Build and deployment** виберіть **Deploy from a branch**.
5. Оберіть гілку `main`, папку `/(root)` і натисніть **Save**.
6. Через 1–3 хвилини сайт буде доступний за адресою:
   `https://ВАШ-ЛОГІН.github.io/3d-quest-9/`

## Що є в грі
- анімована 3D-сцена Three.js: геометричні примітиви, освітлення, частинки;
- обертання сцени перетягуванням миші та масштабування коліщатком;
- 5 послідовних рівнів і 20 тестових запитань;
- 100 балів максимально, оцінка за налаштованою 12-бальною шкалою;
- пояснення після кожної відповіді;
- збереження прогресу у `localStorage`;
- підсумковий екран, друк сертифіката у PDF та експорт CSV.

## Важливо для вчителя
Результати зберігаються лише в браузері та на пристрої, де проходять гру. CSV-файл можна завантажити наприкінці кожного проходження. Централізований збір результатів від усього класу потребує окремого серверного сховища або інтеграції з Google Sheets.
